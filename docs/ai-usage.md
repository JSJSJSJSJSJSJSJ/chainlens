# AI 与检索使用披露

本项目开发使用 Codex AI 助手及并行子任务：后端与测试、React 前端与测试、公开来源研究由独立任务协作，主任务负责契约、集成、文档和验收。AI 参与代码、文档、结构化关系解释及确定性评分规则设计。

实际使用的工具包括：公开网页搜索与页面读取（官方披露原文核查）；PowerShell 与本地 Python/Node.js 运行时；uv、pnpm；pytest、TypeScript、Vite、Vitest 与 Playwright。是否真正运行及结果以 [acceptance.md](acceptance.md) 为准，不以“已编写测试”替代执行证据。

没有使用付费 AI API、AI 密钥、实时行情 API、向量数据库或大模型在线生成分数。用户查询只读取固定研究快照和后端规则结果。AI 不是数据来源；每条关系必须回到 evidence 记录中的原始 URL、定位和短摘录。

验证方法包括：阅读全文相关段落而非只用搜索摘要；检查主体、方向、发布日期、持续性边界；严格输入模型和内容 hash；测试幂等导入、查询语义、评分与异常状态；通过浏览器连接真实后端复核核心流程。测试里的合成公司、日期与冲突不会作为研究数据导入默认数据库。

所有正式研究记录仍为 **待项目作者人工复核**。工具完成的来源核验不能被描述为作者已经审核。优先人工确认：

- 法定上市主体与参与合作子公司的映射是否足够严谨。
- 摘录的上下文是否支持关系中所写的具体范围，特别是供货与直接采购的区别。
- 历史投资与合作事件的日期边界，以及是否需要补充持续性或最新持股披露。
- peer 的比较维度是否适合演示，评分权重是否符合研究目的。
- 原始来源的访问条款、摘录使用边界及 GitHub 公开发布前的数据许可复核。
- 发布目标、最终仓库内容和部署方式；本地验收不代表已经发布或具备生产运维能力。

已知信息截止日为 2026-09-16，资料获取时间逐条保存。工具可访问的资料只是公开资料的一部分，本项目不声称完成全市场供应链调查。
